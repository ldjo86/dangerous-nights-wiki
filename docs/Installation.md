# Installer Dangerous Nights

**Version(s) repérée(s) :** v8.3.3, ZIP pour 1.21.x et 26.1–26.3.

1. Télécharge le ZIP compatible depuis CurseForge.
2. Place-le dans le dossier datapacks/ de ton monde.
3. Exécute /reload ou redémarre le serveur.
4. Confirme sa présence avec /datapack list.
5. Teste ses effets sur une copie du monde.

## Avant d'installer

Les archives locales officielles Dangerous Nights v8.3.3 pour Minecraft 1.21.x et 26.x ont été ouvertes et leurs ressources et fonctions inventoriées. Aucune exécution en jeu n'a été effectuée pour ce wiki.

Vérifie la page CurseForge : https://www.curseforge.com/minecraft/data-packs/dangerous-nights.
