# Dangerous Nights — Questions fréquentes

## Quelle version installer ?

v8.3.3, ZIP pour 1.21.x et 26.1–26.3. Choisis celle qui correspond à ta version Minecraft ; lis la page CurseForge.

## Le guide a-t-il vérifié toutes les mécaniques ?

Non. Les archives locales officielles Dangerous Nights v8.3.3 pour Minecraft 1.21.x et 26.x ont été ouvertes et leurs ressources et fonctions inventoriées. Aucune exécution en jeu n'a été effectuée pour ce wiki.

## Comment obtenir de l'aide ?

Lorsque le dépôt sera créé sur GitHub, signale la version du fichier, celle du jeu, ton chargeur et les étapes qui reproduisent le problème.
