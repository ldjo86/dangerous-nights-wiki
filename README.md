## Ce que ce projet apporte

- Hordes de monstres de plus en plus importantes
- Zombies dont la détection devient plus menaçante
- Mini-boss équipés et butins de survie
- Un niveau d'expérience supplémentaire par nuit entière survécue sans sommeil (selon CurseForge)

<a id="premiers-pas"></a>
## Premiers pas

1. Télécharge le **ZIP correspondant à ta version Minecraft** depuis CurseForge.
2. Dépose-le dans le dossier `datapacks/` de ton monde.
3. Recharge avec `/reload` ou redémarre le serveur, puis contrôle l'installation avec `/datapack list`.
4. Fais tes essais sur une sauvegarde de test avant de modifier ton monde principal.

**Plan conseillé :** survivre une première nuit, sécuriser son abri avant la deuxième, puis décider chaque soir si le risque supplémentaire vaut les récompenses.

## 1. Commencer avec prudence

Prépare une base protégée, des réserves de nourriture et une possibilité de dormir. Le datapack récompense les joueurs qui restent éveillés, mais leur impose aussi une difficulté croissante.

## 2. La série de nuits sans sommeil

Selon la présentation de l'auteur, les hordes et le danger progressent avec les nuits sans dormir. Les zombies peuvent détecter les joueurs de plus loin. La survie d'une nuit complète rapporte un niveau d'expérience supplémentaire.

## 3. Mini-boss et récompenses

Certaines rencontres introduisent des mini-boss équipés et de nouveaux butins. Leurs apparences ne sont pas montrées : laisse le jeu te surprendre. Le contenu des tables de butin est inventorié dans l'atlas technique, sans inventer de chances de chute.

## 4. Quand le compteur revient à zéro

Dormir remet la série de nuits sans sommeil à zéro. Selon la description CurseForge, une mort ne la réinitialise que si elle survient pendant la nuit. La logique exacte doit être confirmée dans les versions utilisées.

## Niveau de vérification

Les fichiers ZIP v8.3.3 pour les familles 1.21.x et 26.x ont été inspectés, dont les fonctions de commandes. Aucun test complet dans une partie Minecraft n'est revendiqué.

Les ZIP contiennent des centaines de fonctions. Le wiki documente les mécanismes annoncés et les fichiers présents, sans publier l'apparence des nouveaux adversaires.
